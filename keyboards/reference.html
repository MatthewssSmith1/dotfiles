Full specification

Read the big label as output, not keycap. Small labels identify physical positions. Green keys show tap / hold. Pass (dashed) falls through active lower layers; None emits nothing. Anomalies are not working-control claims.

Pairing is device-specific

Toucan BLE1/2/3 select ZMK profiles 0/1/2. An empty profile allows pairing; bonds are never cleared automatically. Air60 short RF/BLE presses select, long holds pair in vendor firmware; ignored in USB link mode. Do not long-hold just to test.

Confirm the intended device and mapping before applying. Toucan's two invalid Functions bindings are now corrected to None and verified. Air60 Mac is Enhanced; Windows is Plain with dedicated Shift/Alt. Generic Nav modifiers remain dual-role. See the spec for review and live-test status.
